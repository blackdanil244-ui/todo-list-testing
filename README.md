# Todo-List Testing Documentation

Практическая работа №23: организация тестовой документации с использованием Git и GitHub.

Проект включает требования REQ-01–REQ-10, 15 тест-кейсов, 5 тестовых наборов, 2 учебных баг-репорта, отчёт о тестовом прогоне и матрицу покрытия требований.

> Примечание: тест-кейсы и баг-репорты подготовлены для учебного примера. До запуска приложения результаты выполнения не подтверждены.

## Структура

- `requirements.md` — требования к Todo-List.
- `test-cases/` — 15 тест-кейсов в Markdown.
- `test-suites/` — тестовые наборы.
- `bug-reports/` — примеры баг-репортов.
- `test-run/run-report.md` — отчёт о тестовом прогоне.
- `coverage/coverage-report.md` — покрытие требований тестами.

## Git workflow

Рабочая ветка: `feature/test-cases-marina`. Изменения оформляются через Pull Request в `main`.
