# BUG-001 — Название из пробелов может быть добавлено

- **Статус:** Учебный пример; не подтверждён запуском.
- **Связанное требование:** REQ-03
- **Приоритет:** Средний
- **Окружение:** Заполнить после фактического тестирования (браузер/ОС/версия сборки).
- **Предусловия:** Открыта форма добавления задачи.
- **Шаги воспроизведения:**
  1. Ввести несколько пробелов.
  2. Попытаться добавить задачу.
- **Ожидаемый результат:** Задача из пробелов не создаётся.
- **Фактический результат:** Требует проверки; не заявляется как подтверждённый дефект.
- **Вложения:** Добавить скриншот только при воспроизведении.
