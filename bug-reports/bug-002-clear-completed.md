# BUG-002 — Очистка выполненных может удалить активные задачи

- **Статус:** Учебный пример; не подтверждён запуском.
- **Связанное требование:** REQ-09
- **Приоритет:** Высокий
- **Окружение:** Заполнить после фактического тестирования.
- **Предусловия:** В списке две выполненные и одна активная задача.
- **Шаги воспроизведения:**
  1. Нажать «Очистить выполненные».
  2. Проверить оставшиеся задачи.
- **Ожидаемый результат:** Удаляются только выполненные задачи; активная остаётся.
- **Фактический результат:** Требует проверки; не заявляется как подтверждённый дефект.
- **Вложения:** Добавить скриншот только при воспроизведении.
