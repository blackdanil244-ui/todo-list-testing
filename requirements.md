# Требования к Todo-List

| ID | Требование | Приоритет |
|---|---|---|
| REQ-01 | Пользователь может добавить задачу с непустым названием. | Высокий |
| REQ-02 | Нельзя добавить задачу с пустым названием. | Высокий |
| REQ-03 | Пробелы в начале и конце названия обрезаются; название из пробелов отклоняется. | Высокий |
| REQ-04 | Название задачи длиной до 200 символов включительно принимается. | Средний |
| REQ-05 | Название длиннее 200 символов не принимается. | Средний |
| REQ-06 | Пользователь может отметить задачу выполненной и вернуть её в активные. | Высокий |
| REQ-07 | Пользователь может редактировать и удалять задачу. | Высокий |
| REQ-08 | Фильтры «Все», «Активные» и «Выполненные» отображают соответствующие задачи. | Высокий |
| REQ-09 | Пользователь может удалить все выполненные задачи одной командой. | Средний |
| REQ-10 | Состояние задач сохраняется после перезагрузки страницы; счётчик активных задач корректен, интерфейс адаптивен. | Средний |

## Допущения
Требования составлены для учебного Todo-List, так как исходный код/спецификация приложения не предоставлены. Перед реальным тестированием их следует согласовать с владельцем продукта.
