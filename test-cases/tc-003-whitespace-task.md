# TC-003 — Название из пробелов и обрезка пробелов

- **Требования:** REQ-03
- **Приоритет:** Высокий
- **Шаги:**
  1. Ввести три пробела и попытаться добавить задачу.
  2. Ввести `  Позвонить врачу  ` и добавить задачу.
