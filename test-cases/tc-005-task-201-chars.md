# TC-005 — Название длиной 201 символ

- **Требование:** REQ-05
- **Приоритет:** Средний
- **Шаги:**
  1. Подготовить строку из 201 символа.
  2. Ввести её и попытаться добавить задачу.
- **Ожидаемый результат:** Приложение не принимает название длиннее 200 символов; пользователь получает понятную обратную связь либо ввод ограничивается.
