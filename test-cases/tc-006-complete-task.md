# TC-006 — Отметка задачи выполненной и возврат в активные

- **Требование:** REQ-06
- **Приоритет:** Высокий
- **Предусловия:** В списке есть активная задача.
- **Шаги:**
  1. Отметить задачу как выполненную.
  2. Повторно переключить её статус.
- **Ожидаемый результат:** Сначала задача отмечена выполненной, затем возвращена в активные.
