# TC-013 — Счётчик активных задач

- **Требование:** REQ-10
- **Приоритет:** Средний
- **Предусловия:** В списке две активные и одна выполненная задача.
- **Шаги:**
  1. Проверить счётчик активных задач.
  2. Отметить одну активную задачу выполненной.
- **Ожидаемый результат:** Сначала счётчик равен 2, затем равен 1.
