# TC-015 — Отмена редактирования

- **Требование:** REQ-07
- **Приоритет:** Низкий
- **Предусловия:** В списке есть задача «Исходный текст».
- **Шаги:**
  1. Начать редактирование задачи.
  2. Изменить текст, затем отменить редактирование.
- **Ожидаемый результат:** Сохраняется исходный текст; несохранённые изменения не применяются.
